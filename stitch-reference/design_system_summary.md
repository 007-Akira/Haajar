# Haajar Design Tokens & System Summary

## Color Palette
- **Background:** `#FDFBF7` (Warm Ivory/Cream)
- **Grid Lines:** `#E8E4DE` (Soft Beige-Grey)
- **Primary Text:** `#1A1C1E` (Deep Navy/Charcoal)
- **Secondary Text:** `#60646C` (Muted Slate-Grey)
- **Primary Accent:** `#FF5F1F` (Vivid Orange)
- **Dark Surface:** `#2D2F31` (Charcoal/Deep Navy)
- **Border:** `#D1CDC7` (Soft Grey-Beige)
- **Success:** `#4CAF50` (Muted Green)
- **Warning:** `#FFC107` (Amber)
- **Error:** `#E53935` (Muted Red)

## Typography
- **Headings:** Editorial Display (Bricolage Grotesque / Serif style)
- **Technical/Labels:** Monospaced (JetBrains Mono / Courier Prime style)
- **Body:** Neutral Sans-Serif (Inter / Roboto style)

## Spacing & Rhythm
- **Page Padding:** 24px (Large margins)
- **Vertical Rhythm:** 16px / 24px base increments
- **Touch Targets:** 48px minimum

## Components Style
- **Buttons:** Rectangular with `8px - 12px` radius. Bracketed labels: `[ CONTINUE ]`.
- **Inputs:** Outlined, thin borders (`1px`), mono-labels in brackets.
- **Cards:** Thin outlines, subtle shadows (`0px 4px 8px rgba(0,0,0,0.05)`), grid background overlays.
- **Badges:** Monospaced text in small capsules or brackets: `[ MEMBER ]`.

## Visual Character
- Faint technical grid background on all primary screens.
- Retro-computing/terminal influence via monospaced labels and bracketed syntax.
- High contrast and large touch targets for outdoor usability.
