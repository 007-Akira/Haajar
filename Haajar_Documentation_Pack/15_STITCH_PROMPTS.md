# Stitch Prompt Pack

## Prompt 1: Visual direction

Design an Android mobile application called Haajar for real-time QR-based group attendance during trips and large events. Create a clean, modern, highly readable interface suitable for outdoor use and rapid operation. Use a restrained Malayalam-inspired identity without decorative cultural clichés. The primary users are students, organisers, and faculty. Use large touch targets, clear role badges, strong present/absent hierarchy, and visible online and sync states. Avoid excessive gradients, glassmorphism, dense dashboards, and small controls.

Create:
- Home
- Event overview
- My groups
- Group overview
- Active roll-call card

## Prompt 2: Scanner

Extend the same Haajar design system with a fast QR attendance flow. Create a full-screen scanner showing current group, roll-call name, network state, and pending sync count. After a scan, show a bottom sheet with member name, phone number, role, group, registration answers, current attendance status, and a large Confirm Present button. Include success states for Synced and Pending Sync. Return automatically to scanning after confirmation.

## Prompt 3: Organiser screens

Create organiser screens for Haajar using the existing design system:

- Active roll-call dashboard
- Present/unmarked/absent member list
- Absentee list with call buttons
- Manual attendance
- Join-request approval
- Member management
- Offline roster management
- Sync status

Optimise for one-handed outdoor use.

## Prompt 4: Super organiser

Create a super-organiser dashboard for Haajar showing all groups, combined attendance, active central roll calls, group progress, and groups awaiting offline synchronisation. Add a central roll-call creation screen with multi-group selection and notification controls.

## Prompt 5: Registration builder

Create a mobile registration-form builder for Haajar. Support short text, number, single choice, multiple choice, dropdown, yes/no, and phone fields. Include drag-to-reorder, required toggles, preview, and a strong Publish and Lock confirmation warning. Questions cannot change after publication.

## Prompt 6: Design-system extraction

From the approved Haajar screens, extract a consistent mobile design system including typography, spacing, radius, surfaces, semantic attendance colours, sync states, role badges, buttons, inputs, cards, bottom sheets, dialogs, list rows, empty states, and loading skeletons.
