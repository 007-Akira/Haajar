# Haajar v0.9.0-beta.1

First closed beta release of Haajar.

## Included

- Google authentication
- Trips and hierarchical groups
- Join by code, link, or QR
- Registration forms
- Approval and rejection
- Membership QR
- Role management
- Trip and group edit, archive, and safe delete
- General attendance
- Category and subgroup attendance
- QR scanning
- Manual attendance
- Realtime updates
- Offline subgroup attendance and sync
- Attendance history
- Remaining and absent tracking
- CSV export
- Attendance-start push notifications
- Notification inbox

## Beta status

Intended for 3–10 Android testers.

## Installation

Download `Haajar-v0.9.0-beta.1.apk` from this prerelease.

Android may request permission to install apps from the browser or file manager because this beta is distributed outside Google Play.

## Known issues

- Physical delivery of push notifications still needs confirmation across the beta testers' Android devices.
- The dependency audit retains documented Expo/Metro build-tooling advisories that are not bundled as reachable Haajar Android runtime functionality. A compatible Expo SDK upgrade should address these after the closed beta.
